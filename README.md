# Lieftha Gusphia Hasaz — Data Portfolio

A static portfolio website with responsive layouts, professional experience, project case studies, a profile photo, a downloadable CV, and contact links.

## GitHub Pages publishing

1. Open the public repository `liftahasaz11/liftahasaz11.github.io`.
2. Upload the contents of this folder into the repository root and commit the changes. Upload the extracted files, rather than the ZIP archive; `index.html` should be at the top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish, then open the live address displayed in Settings → Pages.

For the `liftahasaz11` account, the expected address is `https://liftahasaz11.github.io/`. The address is not live until GitHub confirms publication.

## Files

- `index.html`: page content and metadata
- `styles.css`: responsive styles
- `script.js`: expandable project navigation
- `profile-photo.jpeg`: original supplied profile photo
- `Lieftha_Gusphia_Hasaz_CV.pdf`: original supplied CV
- `olist-data-quality.ipynb`: downloadable project notebook
- `.nojekyll`: serve this static website without Jekyll processing

The site uses Google Fonts with local system-font fallbacks. No build command, database, server, or API keys are needed.

## Updates

Edit and commit the relevant files. GitHub Pages republishes updates from the configured branch.
