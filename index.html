Inside the Daegu apartment project+

The question

Which property features help explain SalePrice, and how do linear and tree-based approaches compare for predicting it?

My approach

I explored price distributions and feature relationships, encoded TimeToSubway with an ordinal encoder, and used one-hot encoding for HallwayType and SubwayStation. I compared linear regression, K-nearest neighbors, decision trees, random forests, and XGBoost using a preprocessing pipeline and five-fold cross-validation.

What the analysis showed

Apartment size had the strongest positive correlation among the highlighted features (r ≈ 0.70). Apartment facilities (r ≈ 0.51), basement parking (r ≈ 0.47), and year built (r ≈ 0.45) also showed positive relationships with sale price.

How I evaluated the models

I used RMSE, MAE, and MAPE to inspect different aspects of prediction error, then explored XGBoost tuning. The project reinforced the need to evaluate the actual tuned estimator and distinguish cross-validation results from held-out test performance.

These relationships describe the project dataset; they are not causal effects or guarantees for other markets.

DATA ANALYSIS · PERSONAL PROJECT

Checking the data before trusting the story

A reproducible data quality notebook for the Olist e-commerce dataset, covering missing values, duplicate keys, relational integrity, and order timelines.

pandasData validationJupyter
Read the case studyDownload notebook
Inside the Olist data quality project+

The question

Can customer, order, product, seller, and review data be combined and interpreted reliably?

The checks

The notebook examines seven tables for missing values, repeated primary and composite keys, statistical outliers, unexpected categories, foreign-key coverage, and timestamp consistency. It separates repeated-key group rows from excess rows so duplication counts answer a clear question.

Why the definitions matter

Delivery delays are measured for delivered orders with both actual and estimated dates available. Chronology checks distinguish rule hits from unique affected orders, while absent child records are kept separate from orphan foreign keys.

Explore the work

The downloadable notebook contains the validation workflow. To run it, supply the seven Olist CSV files listed in its first section and set DATA_DIR to their folder. It is saved without executed analysis outputs; historical comparison values are not presented as fresh results.
